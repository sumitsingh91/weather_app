# 🌤️ Weather App

A simple **Weather App** created as a practice project using **HTML, CSS, JavaScript, and OpenWeatherMap API**.

## 📌 About the Project

This project was created **only for practice and learning purposes**.

The main goal of this project is to practice:

* HTML structure
* CSS styling
* JavaScript DOM manipulation
* JavaScript API integration
* Fetch API
* Async/Await
* Working with JSON data
* Handling user input
* Basic error handling

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* OpenWeatherMap API

## ✨ Features

* Search weather by city name
* Display current temperature
* Display weather description
* Display humidity
* Display wind speed
* Display feels-like temperature
* Weather condition icons
* Responsive design
* Enter key support for searching

## 🔑 API

This project uses the **OpenWeatherMap API** to retrieve weather data.

You need to add your own API key in `script.js`:

```javascript
const API_KEY = "YOUR_API_KEY";
```

## 📂 Project Structure

```text
weather-app/
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Add your OpenWeatherMap API key in `script.js`.
4. Open `index.html` in your browser.
5. Enter a city name and search for its weather.
